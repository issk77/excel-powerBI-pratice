# 电商销售PowerBI数据分析项目
## 项目简介
本项目基于模拟电商数据集，完整实现从脏数据清洗、数据建模、DAX指标开发到可视化看板输出的数据分析全流程。数据集包含用户、商品、订单业务表，模拟真实业务中脏数据场景，适合练习Power Query数据清洗、星型模型建模、DAX度量值开发以及业务指标分析。

## 项目文件说明
1. `电商练习数据_第三周.xlsx`：原始业务数据源，包含干净基准表以及带缺陷的脏订单数据表
2. `数据清洗说明.txt`：Power Query清洗规则、剔除逻辑以及清洗后数据校验结果
3. `表关系说明文档.txt`：星型模型设计文档，记录事实表、维度表关联关系、筛选配置、模型校验情况
4. `DAX度量值库.txt`：项目全部业务度量值，包含基础指标、转化指标、时间指标、用户指标、分层指标，附带指标口径与踩坑记录
5. `电商销售看板.pbix`：PowerBI项目文件，完成数据清洗、建模、度量值、交互式看板
6. `analysis-report.md`：业务分析报告，包含指标解读、业务结论与优化建议

## 技术栈
Power Query、Power BI、DAX，参考SQL口径做指标交叉校验

## 分析指标
基础指标：GMV、有效订单数、下单用户数、客单价、商品销量
转化指标：支付转化率、退单金额、退单率、注册用户下单转化率
时间指标：当月GMV、环比、同比、年内累计销售额
用户指标：新客数、老客数、复购用户数、复购率
分层指标：各品类GMV、品类占比

## 运行说明
1. 使用PowerBI打开`电商销售看板.pbix`，可按需刷新数据源；
2. 本项目清洗后脏订单数据时间范围仅2026‑01‑01 ~ 2026‑07‑06，非完整全年数据，部分时间指标存在数据局限；
3. 所有指标均已和Excel/SQL基准结果做校验，文档内记录口径与常见踩坑点。

## 项目收获
练习脏数据识别与处理、星型模型搭建、筛选上下文理解、业务指标口径定义，输出可交互业务分析看板，完整复现数据分析岗位业务分析工作流。
